No triggers. A trigger starts the orchestrator on its own, on a schedule or when a new issue is opened.

Or start from an example:

When
Every day at 05:00
Ask
Address any open issues in this repository.
When
A new issue is opened
Ask
Take a look at the new issue and say what you would do about it.
